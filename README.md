# PhpTest.ru

**Мой учебный проект по профессиональному PHP в стиле ООП.**

Структурированное приложение, которое я пишу, чтобы систематизировать знания и выработать правильные привычки разработки. Здесь я отрабатываю связку PHP + MySQL, работу с Composer, маршрутизацию и архитектуру современных веб-приложений.

## 🧠 Что я изучаю и применяю в этом проекте

- **Объектно-ориентированное программирование (ООП):** классы, наследование, полиморфизм, пространства имён.
- **Автозагрузка PSR-4:** через Composer.
- **Стандарт MVC:** разделение логики, шаблонов и контроллеров.
- **Шаблонизатор Blade:** для чистых и переиспользуемых представлений.
- **Маршрутизация:** обработка запросов через `.htaccess` и самописную логику.
- **API:** создание простых эндпоинтов.

## 🛠️ Стек технологий

| Категория | Технологии |
|-----------|-------------|
| Язык | PHP (8+) |
| База данных | MySQL (через PDO) |
| Автозагрузка | Composer (PSR-4) |
| Шаблоны | Laravel Blade (через `illuminate/view`) |
| Конфигурация | Apache с `.htaccess` |

## 📂 Структура проекта (ключевые папки)

- **`/src`** — основной код приложения (контроллеры, сервисы, модели).
- **`/api`** — скрипты для обработки API-запросов.
- **`/config`** — файлы конфигурации (база данных, параметры).
- **`/content`** — статические ресурсы или скомпилированные ассеты.
